How it works

Built for focus, ready for your account.

Private workspace

Guests can explore the notebook without saving anything. When you sign in, Vex can move the current workspace into a verified user-owned space with Firebase-backed identity and Supabase-backed persistence.

  • Write in guest mode without storage pressure
  • Sign in with Google or one-time email verification
  • Sync notes, boards, and preferences behind Firebase UID scope

Keyboard flows

Shortcuts keep writing moving. The editor supports quick actions, command entry, search, format helpers, and focus-friendly flows designed for rapid capture.

Privacy & trust

Clear storage boundaries.

What is saved

Pages, boards, settings, and typing stats can be persisted into the authenticated user graph when the account is enabled. Guest sessions are intentionally not written to durable storage.

What stays server-side

Authentication and OTP challenge handling remain on the server as part of the backend flow. Temporary verification data is stored under server-only challenge records rather than in the browser.

What is public

Branding, docs, product pages, and public metadata are served from the public site root. Private workspace routes and API routes remain excluded from crawl policies.

FAQ

Quick answers.

Is VexNotes a markdown app or a note-taking app?

It is built as a Markdown-first workspace with writing, structure, and inspiration tools side by side. That makes it a writing tool first, not a brittle document manager.

Does it work without sign-in?

Yes. Guests can open the workspace and use the editor in a local in-memory session. Saving and cross-device sync require authentication.

Can I export my writing?

Yes. Export flows include Markdown, plain text, and print-friendly output to help you move work into other tools when needed.
