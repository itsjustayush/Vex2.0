Vex REST API Reference

The Vex REST API allows developers to programmatically create projects, extract notes, organize workspace files, and perform global searches. All requests are stateless and authenticated using Bearer tokens or Developer API Keys.

lock Hybrid Auth Guard

Authentication

Every request to the Vex API requires a valid Bearer token in the Authorization header:

Authorization: Bearer <YOUR_TOKEN>

You can authenticate using either:

  • Firebase ID Token (Short-lived, generated automatically when logged in)
  • Developer API Key Token (Long-lived, generated in Settings)

GET /api/v1/projects

List All Projects

Retrieves all projects owned by the authenticated user. If no projects exist, standard default workspace projects are returned.

Response Fields

id (string): Unique project identifier (e.g. proj_123)

title (string): Project display name

description (string): Optional project summary

JavaScript / Python / cURL 200 OK 
// Python Example
import requests

headers = {"Authorization": "Bearer YOUR_TOKEN"}
response = requests.get("https://your-domain/api/v1/projects", headers=headers)
print(response.json())
POST /api/v1/projects

Create Project

Creates a new workspace project to group notes and documents.

Request Body Parameters

title (string, required): Project title

description (string): Optional summary

Request Body & Response 201 Created 
// cURL Request
curl -X POST https://your-domain/api/v1/projects \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title": "Machine Learning Notes", "description": "AI research"}'

// Response
{
  "project": {
    "id": "proj_a8f12d",
    "title": "Machine Learning Notes",
    "description": "AI research",
    "created_at": "2026-07-22T08:00:00Z"
  }
}
GET /api/v1/projects/{project_id}/files

List Files in Project

Retrieves all note files belonging to a specific project ID.

JavaScript Fetch 200 OK 
const res = await fetch('/api/v1/projects/proj_default/files', {
  headers: { 'Authorization': `Bearer ${token}` }
});
const data = await res.json();
console.log(data.files);
POST /api/v1/projects/{project_id}/files

Create Note / File

Adds a new note or document file to a specific project.

Request Parameters

title (string, required): Note title

content (string): Note content body

folder (string): Folder name (e.g. "General")

extension (string): File extension ("md", "txt")

Python Request 201 Created 
import requests

payload = {
    "title": "Quantum Computing",
    "content": "Qubits and superposition...",
    "folder": "Physics"
}
res = requests.post(
    "https://your-domain/api/v1/projects/proj_default/files",
    headers={"Authorization": f"Bearer {TOKEN}"},
    json=payload
)
print(res.json())
POST /api/v1/projects/{project_id}/files/{file_id}/copy

Duplicate File / Note

Duplicates an existing file note inside the specified project.

cURL Copy 201 Created 
curl -X POST https://your-domain/api/v1/projects/proj_default/files/nt_12345/copy \
  -H "Authorization: Bearer YOUR_TOKEN"
