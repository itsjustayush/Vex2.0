Vex REST API Reference

The Vex REST API enables full programmatic access to workspace projects, notes, Gemini AI synthesis, and developer API keys. Every endpoint supports live real-time execution directly from this interactive documentation panel.

Base URL: /api/v1
lock Bearer & API Key Auth

Authentication

Pass your access token in the standard HTTP Authorization header or X-API-Key header:

Authorization: Bearer <YOUR_API_KEY_OR_TOKEN>

Supported Token Formats:

  • vex_live_... - Developer API Keys (created via Settings or Keys API)
  • Bearer <Firebase_JWT> - Session token from user login
  • demo-token - Built-in fallback token for quick local testing
Authentication Example 
curl -X GET "http://localhost:3000/api/v1/projects" \
  -H "Authorization: Bearer vex_live_your_api_key" \
  -H "Content-Type: application/json"
GET /api/health

System Health Check

Public endpoint to verify server status, Firestore connectivity, and Gemini AI key readiness. Does not require authentication. 

curl -X GET "http://localhost:3000/api/health"

  .then(res => res.json())
  .then(console.log);

List Workspace Projects

                        

                            Retrieves all projects owned by the authenticated user in reverse chronological order.
                        

                        

                            
Response Fields

                            

                                
projects (array): List of project objects

                                
id (string): Unique ID (e.g. prj_demo123456)

                                
title (string): Project name

                            

                        

                    


                    

                        

                            

                                

                                    
                                    
                                    
                                

                                
                            

                            

                                
curl -X GET "http://localhost:3000/api/v1/projects" \
  -H "Authorization: Bearer demo-token"

                                
import requests
headers = {"Authorization": "Bearer demo-token"}
res = requests.get("http://localhost:3000/api/v1/projects", headers=headers)
print(res.json())

                                
fetch('/api/v1/projects', {
  headers: { 'Authorization': 'Bearer demo-token' }
}).then(r => r.json()).then(console.log);

                            POST
                            /api/v1/projects
                        

                        
Create New Project

                        

                            Creates a new workspace project container for grouping notes.
                        

                        

                            
JSON Body Parameters

                            

                                
title (string, required): Project display name

                                
description (string, optional): Project notes or description

                            

                        

                    


                    

                        

                            

                                

                                    
                                    
                                    
                                

                                
                            

                            

                                
curl -X POST "http://localhost:3000/api/v1/projects" \
  -H "Authorization: Bearer demo-token" \
  -H "Content-Type: application/json" \
  -d '{"title": "AI & Quantum Research", "description": "Notes on transformers and qbits"}'

                                
import requests
payload = {"title": "AI Research", "description": "Deep learning ideas"}
headers = {"Authorization": "Bearer demo-token", "Content-Type": "application/json"}
res = requests.post("http://localhost:3000/api/v1/projects", json=payload, headers=headers)
print(res.json())

                                
fetch('/api/v1/projects', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer demo-token', 'Content-Type': 'application/json' },
  body: JSON.stringify({ title: 'AI Research', description: 'Deep learning ideas' })
}).then(r => r.json()).then(console.log);

Create Note / Document

                        

                            Creates a new note with optional Markdown content, folder structure, and project assignment.
                        

                        

                            
JSON Request Parameters

                            

                                
title (string, required): Note title

                                
content (string, optional): Markdown or plain text body

                                
folder (string, default "General"): Folder path

                                
project_id (string, optional): Associated project ID
